# Demo product photos

Stock photos for the synthetic demo product rows (`services/api/app/ops/demo_images.py`).
Only Unsplash (Unsplash License) and Pexels (Pexels License) photos: both allow free commercial
use without attribution; credit is kept here anyway. No Unsplash+ (premium) photos, no shop images.

Every photo is a **cut-out**: the product alone on a transparent background (background removed
with `rembg` and the BiRefNet-general model, edges decontaminated, stray parts dropped), trimmed,
scaled to an even visual weight and centred with the same padding. The storefront draws the tile
behind it in CSS (`.mm-photo` in `apps/web/src/app/globals.css`), so one file serves light and dark
mode. Served as WebP with alpha (quality 84, metadata stripped) at 800px (`<slug>.webp`) and 400px
(`<slug>-400.webp`) from `/products/`; the 800px PNG masters are in `apps/web/photo-masters/`.
