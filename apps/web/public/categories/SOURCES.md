# Demo category photos

Images for the synthetic demo category rows (`services/api/app/ops/demo_images.py`). Each one is a
small still life composed from 2-3 of the category's own product cut-outs (see
`../products/SOURCES.md`): the first stands at the back, the others in front with a faint occlusion
shadow. So the category tiles use the same Unsplash (Unsplash License) and Pexels (Pexels License)
photos as the products; credit for every photo used is repeated below. The "Photo" column links the
photo of the back item; "Built from" lists all of them.

Transparent WebP (quality 84, metadata stripped) at 800px (`<slug>.webp`) and 400px
(`<slug>-400.webp`), served from `/categories/`; the PNG masters are in `apps/web/photo-masters/`.
